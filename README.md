# Portfolio

A responsive personal portfolio website showcasing my projects and skills as a BS Computer Science student. Built entirely with vanilla HTML and CSS (no Bootstrap, Tailwind, or JS frameworks) — includes a mobile-friendly navbar, animated skill and project cards, and a contact section, all styled with Flexbox.

## Features

- Responsive navigation bar with a mobile menu (pure CSS, no JavaScript)
- About Me section
- Skills section with animated, hoverable skill badges
- Projects section showcasing featured work
- Contact section with a simple form
- Smooth animations and hover effects throughout
- Mobile-friendly, fully responsive layout

## Tech Stack

- HTML5
- CSS3 (Flexbox, CSS animations, custom properties)

## Projects Featured

- **HabitForge** — Flutter & Firebase habit tracking app
- **StyleSync** — PHP & MySQL fashion e-commerce site
- **Palace Booking Management System** — Java Swing desktop app with JDBC/MySQL
- **HIKMAH AI** — LangChain-based Q&A system using a RAG pipeline
